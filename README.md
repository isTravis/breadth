# Breadth

A bread explorer for Gabe Stein's [Breadsheet](https://www.underlay.org/gabestein/breadsheet), a
collection of sourdough formulas on Underlay. Five views of the same 24 recipes:

- **Portraits**: each formula as a cross-section, one ring per ingredient, holes in the crumb by hydration
- **Map**: hydration against richness, with lines to each bread's closest relative
- **Pantry**: which ingredients tie recipes together and which appear once
- **Schedule**: every recipe planned backward from when you want to eat, with night-time steps flagged
- **Lineage**: the breads placed in history, with Gabe's headnotes

It is a single static page (D3 from cdnjs, no framework) served from a Cloudflare Worker.

## Files

- `index.html`: the page; loads `data/breads.js` and `data/schedule.js`
- `data/records.json`: a snapshot of the collection from the Underlay read API
- `data/breads.js`: normalized formulas, generated by `scripts/prep.py`
- `data/schedule.js`: bake timelines, read by hand from each recipe's method steps
- `scripts/bundle.py`: inlines the data into `dist/index.html`

`schedule.js` and the history notes in `index.html` are written by hand, so a recipe Gabe adds
later shows up in every view but has no timeline, and sits under "Not yet placed" in the lineage
view until someone fills it in.

## Commands

Needs Node 20+ and Python 3.

    npm install
    npm run fetch    # pull the latest records from Underlay into data/records.json
    npm run build    # regenerate data/breads.js and dist/index.html
    npm run dev      # build, then serve locally with wrangler
    npm run deploy   # build, then deploy to the Knowledge Futures Cloudflare account

Deploys go straight through wrangler to the Worker named `breadth`; this project is not on the
KF Console.
