# Breadsheet mockups

Four visualization ideas for Gabe's breadsheet collection on Underlay
(https://www.underlay.org/gabestein/breadsheet). Not a KF project; a sketch.

- `index.html` — the mockups (open in a browser; hash routes #portraits, #map, #web, #lineage)
- `data/records.json` — raw records from the Underlay read API (v1.3.0)
- `data/breads.js` — normalized data, built by `python3 -I scripts/prep.py data/records.json > data/breads.js`
